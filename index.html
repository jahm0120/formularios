Formularios en HTML

Texto

Campos de textos básicos: simple, con placeholder, obligatorio(required), de solo lectura(readonly) y deshabilitado(disabled).





Contacto

Campos especializados para datos de contacto: contraseña, correo electrónico, teléfono y url, cada uno con su propio teclado y validación en el navegador.




Numéricos

Campo para valores numéricos: un número con límites(min/max) y un deslizador(range) para elegir un valor dentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana del mes y año.






Selección

Controles de selleción: elegir un color, marcar una casilla, elegir una opción de un grupo de radios y subir un archivo.





listas desplegables(select)

Listas desplegables con el elemento select: una opción simple, una con valor preseleccionado (selected), una agrupada con optgroup, una de selección múltiple (multiple) y una deshabilitada (disabled)
